# Mora для iPhone

Нативное приложение SwiftUI для iOS 17+ (iPhone и iPad). Использует то же ядро `FinanceCore`, что и Mora для Mac: формат `ledger.json`, проверки данных, отчеты, импорт CSV, история изменений, курсы валют, пересчет Visa и общая база Supabase совпадают.

## Возможности

- **Обзор:** общий капитал, доходы, расходы и разница за месяц, денежный поток, расходы по категориям, последние операции, сводка, ближайший платеж и бюджеты.
- **Операции:** поиск, группировка по дням, фильтры по периоду, типам, счетам и категориям, смахивание для удаления и дублирования, множественный выбор, разделение по категориям, похожая операция, экспорт CSV.
- **Новая операция:** расход, доход и перевод между счетами, валюта покупки с пересчетом по курсу Visa и комиссией счета, автоматическая категория, подсказки названий и тегов, баланс после операции.
- **Аналитика:** месяцы, недели, дни и выбранные даты, календарь расходов, доли категорий.
- **Счета:** остатки, архив, удаление архивных счетов, история операций счета.
- **Ещё:** категории и правила, бюджеты, цели, регулярные платежи, импорт CSV и история импортов, общая база и входящие Apple Pay, настройки, резервные копии JSON, отмена и возврат изменений.

Язык интерфейса совпадает с языком iPhone (русский или английский); отдельно для Mora его можно сменить в «Настройки iPhone → Mora → Язык». Суммы можно скрыть для скриншотов; в переключателе приложений содержимое закрывается.

## Данные

По умолчанию учет хранится только на iPhone: `Application Support/Mora/ledger.json` внутри контейнера приложения, с защитой файлов iOS. Перенести данные с Mac можно резервной копией JSON (Настройки → «Восстановить из резервной копии…») или через [общую базу](../cloud/README.md): iPhone входит отдельным пользователем того же проекта Supabase, открывает базу из списка или по коду приглашения с Mac. Сессия хранится в Связке ключей iPhone.

## Сборка для симулятора

Нужны Xcode 26+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (только для пересоздания проекта из `project.yml`).

```sh
zsh scripts/build-ios.sh
```

Или откройте `iOS/MoraiOS.xcodeproj`, выберите схему **MoraiOS** и симулятор.

## Установка на iPhone

1. Войдите своим Apple ID в Xcode → Settings → Accounts (бесплатного достаточно) и скопируйте Team ID нужной команды.
2. Создайте `iOS/Local.xcconfig`. Git его не отслеживает, а `Signing.xcconfig` подключает к проекту:
   ```
   DEVELOPMENT_TEAM = ABCDE12345
   ```
   Если идентификатор `com.mora.finance.ios` недоступен вашей команде, добавьте свой: `MORA_BUNDLE_IDENTIFIER = com.example.mora`.
3. Подключите iPhone кабелем, разблокируйте и нажмите «Доверять». Включите «Настройки → Конфиденциальность и безопасность → Режим разработчика» (пункт появляется после первого подключения к Xcode).
4. Запустите установку. Скрипт соберет Release-версию, подпишет ее, установит и откроет Mora. Если подключено несколько iPhone, передайте имя или модель: `zsh scripts/install-ios.sh "13 mini"`.
   ```sh
   zsh scripts/install-ios.sh
   ```
5. При первой установке iPhone попросит разрешить разработчика: «Настройки → Основные → VPN и управление устройством → Apple Development → Доверять».

С бесплатной командой подпись действует 7 дней. Потом Mora перестанет открываться, пока вы снова не запустите `zsh scripts/install-ios.sh`; переустановка сохраняет данные. Не удаляйте приложение с iPhone: локальный учет удалится вместе с ним. Перед этим сделайте резервную копию JSON или подключите общую базу. Платная команда Apple Developer подписывает на год.

## Тесты

```sh
cd iOS && xcodebuild test -project MoraiOS.xcodeproj -scheme MoraiOS -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```

`LedgerRepository.swift` и `ChangeDescription.swift` подключаются напрямую из `Sources/Mora`: в них не должно быть AppKit. Строки интерфейса пишутся по-русски; английские переводы берутся из общего `en.json` и `Mora/Resources/MobileStrings.json`, тест `LocalizationTests` проверяет, что перевод есть у каждой строки.

В Debug-сборке для проверки экранов есть аргументы запуска: `--demo`, `--tab transactions|analytics|accounts|more`, `--more settings|categories|cloud|imports`, `--sheet transaction|account|category|welcome`.
