# Telegram-бот для покупок

Бот записывает покупки в общую базу Mora через строгую форму. Свободный текст он не разбирает, поэтому сумму невозможно прочитать неправильно. Компьютер включённым держать не нужно: бот работает как функция Supabase на webhook.

Есть два способа записи:

- **Форма (Telegram Mini App).** Её открывает кнопка «Добавить» слева от поля ввода. Поля: сумма, валюта, продавец, категория, счёт, дата и заметка. Недавние продавцы подставляют счёт, валюту и категорию одним нажатием. Форма работает в любой версии Telegram.
- **Виджет в чате (HTMLBubbles, Telegram 13.2).** Показывает итоги за сегодня и за месяц, а также кнопки недавних продавцов с экранной клавиатурой для суммы. Ввода текста в виджетах нет: так устроены HTMLBubbles. «Новая трата» и «Подробнее» сразу открывают форму по прямой ссылке бота (шаг 8 установки); без неё бот присылает сообщение с кнопкой формы. Виджеты — часть Bot API 10.4 (9 ноября 2026); в обычном Telegram их можно отправлять только в личный чат с ботом, и их нельзя переслать.

Покупка в валюте счёта записывается сразу, с тегом `Telegram`, выбранной категорией и заметкой. Если у счёта задана комиссия за покупки в его валюте, она добавляется так же, как к покупкам Apple Pay. Если категория не выбрана, её определяют правила Mora. Покупка в другой валюте попадает во входящие. Открытая Mora пересчитывает её по курсу Visa, как покупки Apple Pay; категорию в этом случае предлагает Mora. Записанные покупки Mora собирает в импорт, который можно откатить. После каждой записи бот присылает в чат квитанцию, а в форме и в виджете на пару секунд появляется котик Яр, который целует Настеньку.

## Как это устроено

| Часть | Где | Что делает |
|---|---|---|
| Миграция `supabase/migrations/20261109052051_telegram_bot.sql` | Supabase | `mora_phone_context` отдаёт форме счета, категории, недавних продавцов и итоги. `mora_phone_add_purchase` записывает покупку. |
| Функция `supabase/functions/mora-telegram` | Supabase Edge Functions | Принимает webhook бота, проверяет подпись Telegram у формы, отвечает виджету. |
| Форма `telegram/miniapp/index.html` | Любой статический HTTPS-хостинг | Одна страница без секретов. Адрес функции передаётся параметром `?api=` или записывается в опубликованную копию как `<html data-api="…">`. Записанный адрес главнее параметра, поэтому ссылка из BotFather с потерянным или неверным `?api=` всё равно работает. |
| `telegram/setup.mjs` | Ваш Mac | Настраивает webhook, команды и кнопку «Добавить». |

Supabase не отдаёт HTML-страницы из функций, поэтому форма лежит на отдельном статическом хостинге: GitHub Pages, Cloudflare Pages или любом другом.

## Безопасность

- Ключ телефона и токен бота хранятся только в секретах функции. В Telegram и в форму они не попадают.
- Форма каждый раз отправляет подписанные Telegram данные (`initData`). Функция проверяет подпись токеном бота и срок давности (сутки).
- Записывать могут только Telegram ID из `TELEGRAM_ALLOWED_USERS`. Остальным бот отвечает их ID и ничего не записывает.
- Webhook принимает только запросы с секретом `TELEGRAM_WEBHOOK_SECRET`.
- Ключ телефона для бота может больше, чем ключ Apple Pay: он читает названия активных счетов и категорий расходов, а также свои собственные покупки. Остальные операции базы он не видит. Создайте для бота отдельный ключ, тогда его можно отозвать, не трогая Apple Pay.

## Установка

1. **Бот.** В Telegram откройте @BotFather → `/newbot`. Сохраните токен: это пароль бота.
2. **Миграция.** Выполните `supabase/migrations/20261109052051_telegram_bot.sql` в SQL Editor после остальных миграций.
3. **Ключ телефона.** В Mora на Mac: **Настройки → Общая база и Apple Pay**. Создайте ключ телефона с меткой, например «Telegram · Настя», и счётом по умолчанию. Скопируйте ключ.
4. **Форма.** Опубликуйте папку `telegram/miniapp` на статическом хостинге с HTTPS. Адрес формы будет таким:
   `https://<хостинг>/miniapp/?api=https://<проект>.supabase.co/functions/v1/mora-telegram`
5. **Функция.** Разверните её через CLI (функция состоит из двух файлов, `index.ts` и `widget.ts`):
   ```bash
   supabase functions deploy mora-telegram --no-verify-jwt
   ```
   Затем задайте секреты. Сгенерируйте случайный `TELEGRAM_WEBHOOK_SECRET`, например командой `openssl rand -hex 32`. `TELEGRAM_ALLOWED_USERS` пока оставьте пустым:
   ```bash
   supabase secrets set TELEGRAM_BOT_TOKEN=... MORA_PHONE_TOKEN=... TELEGRAM_WEBHOOK_SECRET=... \
     TELEGRAM_ALLOWED_USERS= TELEGRAM_MINIAPP_URL='https://<хостинг>/miniapp/?api=https://<проект>.supabase.co/functions/v1/mora-telegram'
   ```
6. **Webhook.** На Mac выполните:
   ```bash
   TELEGRAM_BOT_TOKEN=... TELEGRAM_WEBHOOK_SECRET=... \
   MORA_FUNCTION_URL=https://<проект>.supabase.co/functions/v1/mora-telegram \
   TELEGRAM_MINIAPP_URL='https://<хостинг>/miniapp/?api=https://<проект>.supabase.co/functions/v1/mora-telegram' \
   node cloud/telegram/setup.mjs
   ```
   Скрипт скажет, принял ли webhook бета-версию Bot API 10.4. Если принял, кнопки виджета работают.
7. **Участники.** Каждый, кто будет записывать покупки, пишет боту `/start` и получает свой Telegram ID. Добавьте ID через запятую в `TELEGRAM_ALLOWED_USERS` (`supabase secrets set TELEGRAM_ALLOWED_USERS=111,222`) и попросите снова написать `/start`.
8. **Прямая ссылка на форму.** В @BotFather: `/mybots` → бот → **Bot Settings → Configure Mini App → Enable Mini App**, укажите тот же адрес формы. Это Main Mini App бота, её ссылка — `https://t.me/<бот>` (виджет добавляет `?startapp`). Запишите эту ссылку в `TELEGRAM_MINIAPP_LINK`, и «Новая трата» и «Подробнее» будут открывать форму сразу, «Подробнее» — с подставленными продавцом и суммой. Подойдёт и ссылка `https://t.me/<бот>/<имя>` от `/newapp`.

Команды бота: `/start` присылает кнопку формы и виджет, `/widget` присылает свежий виджет.

### Настройки в Vault вместо секретов функции

Без Supabase CLI (например, при развёртывании через Supabase MCP или в панели) настройки можно хранить в Supabase Vault. Нужна миграция `20261109052052_telegram_bot_settings.sql`. Функция читает секреты с именами `mora_telegram_<настройка>` служебной ролью и применяет изменения в течение минуты. Секреты функции с тем же смыслом имеют приоритет.

| Секрет функции | Секрет Vault |
|---|---|
| `TELEGRAM_BOT_TOKEN` | `mora_telegram_bot_token` |
| `MORA_PHONE_TOKEN` | `mora_telegram_phone_token` |
| `TELEGRAM_WEBHOOK_SECRET` | `mora_telegram_webhook_secret` |
| `TELEGRAM_ALLOWED_USERS` | `mora_telegram_allowed_users` |
| `TELEGRAM_MINIAPP_URL` | `mora_telegram_miniapp_url` |
| `TELEGRAM_MINIAPP_LINK` | `mora_telegram_miniapp_link` |

Создать секрет: `select vault.create_secret('<значение>', 'mora_telegram_bot_token');`. Изменить: `select vault.update_secret(id, '<новое значение>') from vault.secrets where name = 'mora_telegram_allowed_users';`.

## Ограничения

- Виджеты (HTMLBubbles) показываются только в клиентах Telegram, которые их поддерживают (слой 233, Telegram 13.2). На старых клиентах вместо виджета будет «неподдерживаемое сообщение». Форма работает везде.
- Код виджета фиксируется при отправке: после обновления функции пришлите `/widget`, старые виджеты в чате останутся прежними.
- Виджет обновляет итоги после своих записей и по кнопке ↻. Записи через форму он видит после ↻ или `/widget`.
- Категория и заметка из формы сохраняются и у покупок в другой валюте: они ждут во входящих вместе с покупкой (миграция `telegram_capture_category`), и при пересчёте по курсу Visa сервер ставит категорию из формы, если при проверке не выбрана другая.
- Если бот удалить из Telegram или отозвать ключ телефона, форма перестанет записывать. Уже записанные покупки останутся.
