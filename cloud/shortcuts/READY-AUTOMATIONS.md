# Готовые автоматизации для iOS 27

В iOS 27 автоматизацией можно поделиться как обычной быстрой командой: триггер
сохраняется внутри файла. Mora кладёт такие файлы в приложение. На iPhone с iOS 27
кнопка «Настроить» в «Ещё → Автоматизация» тогда предлагает добавить готовую
автоматизацию. Вручную пользователю остаётся только включить её переключатель
на вкладке «Автоматизация» в «Быстрых командах».

Если файла нет в сборке или iOS старше 27, Mora показывает пошаговую сборку.

## Какие файлы нужны

Имя файла должно совпадать в точности: по нему Mora находит автоматизацию.

| Файл | Триггер | Действие Mora и его поля |
| --- | --- | --- |
| `Mora Apple Pay.shortcut` | «Транзакция» (Wallet), карты не выбирать | **Start Wallet Payment**: Merchant → «Продавец», Name → «Имя», Card or Pass → «Карта или пропуск»; затем **Finish Wallet Payment**: Amount → «Сумма». Уже в приложении, его собирает `scripts/sign-wallet-automation.sh` |
| `Mora Wallet Notification.shortcut` | «Уведомление», приложение Wallet, без фильтров по тексту | **Log Wallet Notification**: Title → Title, Subtitle → Subtitle, Body → Body |
| `Mora Bank SMS.shortcut` | «Сообщение», «Сообщение содержит» = `$`, отправителя не выбирать | **Log Bank Message**: Text → «Содержимое», From → «Отправитель». Поле Title оставить пустым |
| `Mora Bank Notification.shortcut` | «Уведомление», приложение банка любое (пользователь сменит его после добавления) | **Log Bank Notification**: Title → Title, Body → Body, App: вписать название приложения банка |

В каждом поле должно стоять свойство входных данных триггера, а не вся переменная:
нажмите на вставленную переменную «Входные данные команды» и выберите свойство.

Для всех четырёх: «Запускать сразу», «Уведомлять о запуске» выключено. В файле не
должно быть ничего личного: ни выбранных карт, ни номеров, ни текста сообщений.

## Как сделать файл

### На iPhone с iOS 27

1. Обновите Mora на iPhone до 1.0.48 или новее, иначе в списке не будет действия
   **Log Bank Notification**.
2. Откройте «Быстрые команды» → «Автоматизация» → «+» и соберите автоматизацию по
   таблице выше.
3. Переименуйте её в точности как в столбце «Файл», без `.shortcut`, например
   `Mora Bank SMS`.
4. Нажмите и удерживайте автоматизацию → «Поделиться» → «Параметры» и проверьте,
   что делиться можно с кем угодно. Затем выберите «Сохранить в Файлы» и сохраните
   на iCloud Drive или отправьте файл на Mac через AirDrop.
5. На Mac проверьте файл (команда ниже). Если триггер потерялся, iOS отдала команду
   без автоматизации: такой файл не подходит.

### На Mac с macOS 27

Если автоматизация уже есть как файл без подписи, подпишите его:

```bash
shortcuts sign --mode anyone --input "Mora Bank SMS (unsigned).shortcut" --output "Mora Bank SMS.shortcut"
```

Подписывайте на macOS 27: macOS 26 при подписи выбрасывает триггер. Подпись
действует около года. Дату окончания показывает проверка, поэтому пересоздайте
файл заранее.

## Проверка

```bash
python3 cloud/shortcuts/check_automation_file.py "Mora Bank SMS.shortcut"
```

Проверка выводит, кем и до какого числа подписан файл, какой в нём триггер и какие
действия Mora. Она завершается ошибкой, если файл не подписан, триггера нет или
действия не те.

## Как передать файлы в приложение

Пришлите файлы Claude или положите их в `iOS/Mora/Resources/` под точными именами
и попросите встроить. Встраивание — это проверка каждого файла, `xcodegen generate`
в `iOS/` (проект перечисляет файлы ресурсов) и обычный выпуск новой версии.
В коде ничего менять не нужно: кнопка «Добавить в Быстрые команды» появляется сама,
как только файл есть в сборке.

## Что видит пользователь

1. «Ещё → Автоматизация» → «Настроить» у нужной автоматизации.
2. «Добавить в Быстрые команды» → «Быстрые команды» → «Добавить быструю команду».
3. «Открыть автоматизации»: Mora открывает вкладку «Автоматизация». Для SMS
   пользователь проверяет символ валюты, для уведомлений банка выбирает приложение
   банка. Затем включает переключатель справа от автоматизации. iOS добавляет чужие
   автоматизации выключенными, и включить их может только владелец iPhone.
4. Следующая покупка появляется на последнем шаге помощника и в журнале.
