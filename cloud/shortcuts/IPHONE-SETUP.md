# Apple Pay → Mora: настройка iPhone

## Схема с 27 октября 2026

- **Один ключ на человека.** Ключ создаётся в Mora один раз и работает для всех карт этого человека на его iPhone.
- **Одна автоматизация на все карты.** Автоматизация «Транзакция» передаёт отправителю сумму, продавца и название карты из поля «Карта или пропуск».
- **Счёт выбирается в Mora.** Новая карта появляется после первой покупки. Mora присылает уведомление «Новая карта в Wallet: выберите счёт»; счёт выбирается в форме проверки или в разделе «Карты Apple Pay». Дальше покупки этой картой записываются туда автоматически.
- Если iPhone не передал название карты, покупка идёт в основной счёт ключа, как раньше.

Сначала примените миграцию `cloud/supabase/migrations/20261027120000_wallet_cards.sql`, затем устанавливайте отправитель с полем `card`. Без миграции сервер не знает параметр `p_card`, и такие покупки не будут приняты. Старые отправители работают и после миграции.

## Почему иногда нет суммы

iOS запускает автоматизацию после касания терминала и недолго ждёт, пока банк или оператор пришлёт сумму в Wallet ([форум Apple](https://developer.apple.com/forums/thread/765516)). Обычно сумма успевает прийти, но у части покупок она приходит позже. Это проезд по Express Transit, отложенная авторизация на заправках и в отелях, медленный ответ эмитента. Тогда команда получает транзакцию без суммы. Входные данные команды — снимок на момент запуска: повторное чтение и паузы не дают обновления и мешают фоновому запуску.

Поэтому отправитель не ждёт и не подставляет суммы. Покупка без суммы сохраняется во входящих с продавцом, картой и временем. В форме проверки Mora подставляет сумму прошлой покупки у того же продавца в её исходной валюте и помечает это. Сумму нужно подтвердить одним сохранением. Правил для отдельных продавцов или городов нет.

## Подготовка отправителя

1. В Mora создайте ключ телефона: «Общая база и Apple Pay → Apple Pay → расход». Основной счёт нужен только для покупок без названия карты.
2. Создайте локальный JSON-конфиг с `projectURL` и публичным `publicKey` своего проекта. Привилегированный серверный ключ использовать нельзя.
3. Выполните:

```sh
python3 cloud/shortcuts/build_shortcuts.py \
  --config /path/to/private-config.json \
  --output-dir build/shortcuts
```

4. Используйте `Mora-ApplePay-Dictionary.unsigned.shortcut`. Подписывайте штатной командой Apple. Режим `anyone` нотариализует файл через iCloud, поэтому так подписывают только шаблон без личного ключа. Личные файлы подписывайте локально: `shortcuts sign --mode people-who-know-me --input INPUT --output OUTPUT`.
5. Импортируйте файл на iPhone и замените нулевой ключ в первом действии «Текст» своим. Не публикуйте команду с ключом.

## Автоматизация на iPhone

Быстрые команды → Автоматизация. Удалите старые автоматизации «Транзакция», чтобы покупка не отправлялась дважды. Затем «+» → **Транзакция**:

- Отметьте **все свои карты**. Если iOS разрешает выбрать только одну карту, сделайте по автоматизации на карту с теми же действиями: ключ и отправитель остаются общими.
- Включите **Запускать сразу**, «Уведомлять о запуске» выключите.
- Создайте **новую пустую автоматизацию** с действиями:

| # | Действие | Значение |
|---|---|---|
| 1 | Текст | Входные данные команды → тип **Транзакция**, свойство **Сумма** |
| 2 | Текст | Снова **Входные данные команды** (не результат шага 1) → **Продавец** |
| 3 | Текст | Снова **Входные данные команды** → **Карта или пропуск** |
| 4 | Словарь | `amount` = Текст 1, `merchant` = Текст 2, `card` = Текст 3, `currency` = пусто. Все значения — Текст |
| 5 | Запустить быструю команду | отправитель; входные данные = **Словарь** из шага 4; «Показывать при запуске» выключено |

Автоматизации iPhone не переносятся файлом, поэтому эти действия настраиваются вручную. Не используйте ожидание, уведомления и окно результата.

Проверка — следующая обычная покупка каждой картой. Первая покупка новой картой ждёт выбора счёта в Mora.

## Ограничения

- Для отправки нужен интернет. Офлайн-очереди нет.
- Автоматизация срабатывает при касании терминала выбранной картой. Оплаты в приложениях, на сайтах, другой картой или с другого устройства не гарантируются. Отклонённые платежи не превращайте в расходы.
- Если автоматизация иногда не запускается вовсе, пользователи на форуме Apple советуют отключить сводку уведомлений для Wallet. Официально это не подтверждено.
- Не запускайте отправитель вручную для уже отправленной покупки: новый запуск создаёт новый идентификатор.

Сервер принимает коды и символы валют из суммы; явное поле `currency` имеет приоритет. `$` трактуется как USD, `€` как EUR, `₽` как RUB. Если валюта покупки отличается от валюты счёта карты, Mora пересчитывает сумму по курсу Visa с комиссией счёта.

Ответ `recorded` означает, что расход записан. `pending` — покупка доставлена во входящие: она ждёт пересчёта, выбора счёта для новой карты или проверки. Локальные автотесты не заменяют проверку реальной оплатой на каждой версии iOS.

Источники: [Apple: Transaction triggers](https://support.apple.com/guide/shortcuts/transaction-triggers-apd65c67538a/ios), [Apple Developer Forums: Transaction trigger timeouts](https://developer.apple.com/forums/thread/765516).
