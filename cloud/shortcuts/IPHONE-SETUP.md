# Apple Pay → Mora: настройка без уведомлений

## Актуальная схема с 25 октября 2026

Поля Wallet нужно извлекать **внутри автоматизации «Транзакция»**, до вызова другой команды. Отдельная команда получает обычный словарь. Это исключает передачу непрозрачного объекта Wallet между командами; исправление доступности полей на конкретной карте требует проверки настоящей оплатой.

Пятисекундную диагностику больше не используйте для обычных оплат. На предоставленном примере оба снимка были пустыми, хотя Wallet и банковское уведомление содержали данные. Повторное чтение уже переданного объекта не получило обновление. Новые рабочие шаблоны не содержат задержек, уведомлений и окон результата. Они отправляют один запрос на запуск.

## Подготовка отправителя

1. В Mora создайте ключ телефона для нужного счёта и карты. Для каждой карты/участника нужен отдельный ключ.
2. Создайте локальный JSON-конфиг с `projectURL` и публичным `publicKey` своего проекта; привилегированный серверный ключ запрещён.
3. Выполните:

```sh
python3 cloud/shortcuts/build_shortcuts.py \
  --config /path/to/private-config.json \
  --output-dir build/shortcuts
```

4. Используйте `Mora-ApplePay-Dictionary.unsigned.shortcut`. Подпишите штатной командой Apple. `anyone` выполняет нотариализацию через iCloud, поэтому так подписывают только шаблон без личного ключа. Настроенные личные файлы подписывайте локально: `shortcuts sign --mode people-who-know-me --input INPUT --output OUTPUT`. Получатель должен иметь контакт отправителя либо использовать тот же Apple Account.
5. Импортируйте файл на iPhone и замените нулевой ключ в первом действии «Текст» своим. Не публикуйте команду с ключом. В личных готовых файлах ключ уже подставлен.

## Четыре действия в автоматизации iPhone

Откройте «Быстрые команды → Автоматизация → Транзакция», выберите нужную карту и немедленный запуск. Оставьте одну автоматизацию на эту карту. Старый запуск `Wallet-5s` заменяется, а не добавляется рядом.

1. **Текст**: вставьте переменную «Входные данные команды» / `Shortcut Input`, задайте тип **Транзакция / Transaction**, свойство **Сумма / Amount**.
2. **Текст**: снова выберите **исходные входные данные автоматизации**, тип **Транзакция / Transaction**, свойство **Продавец / Merchant**. Не используйте результат первого «Текста».
3. **Словарь / Dictionary**, все значения текстовые:

   | Ключ | Значение |
   | --- | --- |
   | `amount` | результат первого «Текста», содержащий сумму |
   | `merchant` | результат второго «Текста», содержащий продавца |
   | `currency` | пустая строка, если отдельный код валюты недоступен |

4. **Запустить быструю команду**: выберите тихую команду отправителя. В её поле входных данных явно выберите **Словарь из пункта 3**. Объект Transaction в отправитель не передаётся.

Отключите «Уведомлять о запуске» / `Notify When Run`, если такой переключатель доступен. Собственных уведомлений у отправителя нет; системные сообщения и ошибки iOS управляются самой iOS. Автоматизации iPhone не переносятся готовым файлом обычной команды, поэтому эти четыре действия на телефоне надо настроить вручную.

После следующей обычной покупки проверьте её в Mora. Тестовая команда `Mora-Quiet-SelfTest` использует искусственные значения и не обращается к облаку; успешный запуск проверяет формирование полей запроса, но не доступность Wallet на iPhone. Не тестируйте отправитель с выдуманной покупкой в настоящей базе.

## Ограничения и восстановление

- Интернет нужен для отправки. Сейчас офлайн-очереди нет. В представленном сбое запрос успешно дошёл до сервера, поэтому отсутствие сети не объясняет пустые поля этого события.
- Автоматизация Apple Wallet запускается при касании терминала выбранной картой. Не следует ожидать все оплаты в приложениях, на сайтах, другой картой или другим устройством. Отклонённые платежи в Wallet не нужно превращать в расходы.
- Если поля пусты даже при извлечении внутри автоматизации, сервер не может восстановить их из истории Wallet. Наличие суммы в Wallet позднее не гарантирует её доступности в момент триггера. Для уже пустых событий нужны чек/выписка/вручную проверенные данные.
- На iOS 18/26 автоматическое чтение push-уведомлений стороннего банка недоступно как универсальный триггер Shortcuts. Банковское SMS или email может быть отдельным источником, но требует своего формата и защиты от дубликатов с Wallet. Скриншот push не подтверждает наличие SMS.
- Не запускайте отправитель повторно для той же покупки: новый запуск создаёт новый идентификатор. Повтор запроса допустим только с прежним идентификатором.

Сервер принимает поддерживаемые коды и символы валют из суммы; явное поле `currency` имеет приоритет. `$` трактуется как USD, `€` как EUR, `₽` как RUB. Для других долларовых валют нужен явный код. При отличии валюты покупки от валюты счёта открытая Mora пересчитывает сумму по курсу Visa и комиссии счёта. Не подставляйте валюту счёта вместо валюты покупки.

Ответ `recorded` означает запись, `pending` — приём во входящие; увидеть результат можно в Mora. Пустые события не превращаются в расходы с выдуманной суммой. Локальные автотесты и запуск в macOS Shortcuts не заменяют проверку реальной оплатой на каждой версии iOS.

Источники: [Apple: Transaction triggers](https://support.apple.com/guide/shortcuts/transaction-triggers-apd65c67538a/ios), [Apple: communication triggers, iOS 18](https://support.apple.com/guide/shortcuts/communication-triggers-apdd711f9dff/8.0/ios/18.0).
