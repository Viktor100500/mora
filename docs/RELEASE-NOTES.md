Mora 1.5.0 is the first public macOS preview.

- Local personal finance, multi-currency accounts, CSV import, backups and analytics.
- Welcome screen in Russian and English, with reporting-currency selection.
- Per-account currency-conversion fee and direct access to Analytics from Overview.
- Optional MCP and self-hosted shared ledger integrations.

Requirements: macOS 14+. Download arm64 for Apple Silicon or x86_64 for Intel if available. Unzip and move Mora.app to Applications. Checksums are attached beside each ZIP.

This preview uses ad hoc signing and has not been notarized by Apple. macOS may require manual approval in Privacy & Security after you verify the download source. Do not disable system-wide security protections.

The application starts without a personal ledger, cloud project or credentials. Your data stays local unless you explicitly configure optional integrations. Wallet capture remains experimental and requires verification against bank records.
