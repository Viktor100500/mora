# Карты Wallet и команда для iPhone

В Mora на Mac откройте «Общая база и Apple Pay» → «Создать команду для iPhone…».

1. Укажите название телефона.
2. Добавьте свои карты с названиями из Wallet. Если карты называются одинаково, сначала задайте им различимые названия, если Wallet это позволяет, или настройте отдельную автоматизацию для каждой карты вручную. Mora не получает список карт iPhone.
3. Для каждой карты выберите счёт, например Chase → «Chase, Viktor», Raiffeisen → нужный счёт Raif. Суммы в другой валюте обрабатываются обычным пересчётом Mora.
4. Нажмите «Создать и сохранить команду…». Mora сохранит привязки в общей базе и локально подпишет личный файл Apple Shortcuts.
5. Передайте файл на iPhone через AirDrop и добавьте команду. В существующей автоматизации «Транзакция» выберите её вместо прежней. Входные данные — исходная транзакция целиком. Для каждой карты должна остаться одна автоматизация.

Новый ключ создаётся вместе с привязками. Старые команды продолжают работать со старыми ключами; само обновление Mora не меняет установленную команду iPhone. Ключи можно отозвать в разделе ручной настройки. При ошибке сохранения повторите сохранение в том же окне: новый ключ не будет создан повторно.

Команда тихая: читает сумму, продавца и «Карту или пропуск» сразу и через 5 секунд. Для каждого поля выбирает непустое позднее значение, иначе первое. Если суммы или продавца нет, запрос не отправляет. Если не определилась карта или её название не совпало с настройкой, покупка ждёт проверки в Mora и не записывается автоматически на основной счёт телефона. Привязку новой карты можно поправить в «Карты Apple Pay».

Названия сопоставляются без учёта регистра и повторных пробелов, отдельно для каждого ключа телефона. Mora не угадывает карту по продавцу или сумме. Исторические операции автоматически на другой счёт не переносятся.

При первой реальной оплате оставьте iPhone разблокированным, чтобы можно было ответить на запрос доступа к Wallet, если iOS его покажет. Проверьте отдельными оплатами каждую карту. Подпись файла и локальные тесты не проверяют работу триггера Wallet на конкретном телефоне.

Для отправки нужен интернет. Команда не сохраняет офлайн-очередь и не повторяет отправку при появлении сети. Пауза не гарантирует, что Wallet обновит входной объект. Сообщение iOS «There was a problem running the automation» не указывает причину: при нём нужно проверить, дошло ли событие в Mora. До ручного добавления проверьте наличие покупки, поскольку ответ сервера может потеряться уже после записи.
