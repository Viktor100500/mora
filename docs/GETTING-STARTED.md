# Первый запуск Mora

## 1. Выберите язык и валюту отчетов

На экране приветствия выберите русский или English. Валюта отчетов нужна для общих итогов: например, при счетах USD и EUR вы можете смотреть капитал в EUR. Ее можно изменить в настройках, когда доступны нужные курсы.

**Посмотреть демо** открывает вымышленные данные. Они не записываются в ваш учет. Когда будете готовы, нажмите **Начать свой учет** в баннере демо.

## 2. Создайте первый счет

Нажмите **Создать первый счет**, введите понятное название и выберите валюту. Начальный остаток — деньги на счете до первой записываемой операции. Например, если до первой покупки было €100 и покупка стоила €10, начальный остаток — €100, а после записи получится €90.

Для импорта прошлой выписки задайте остаток перед ее первой строкой. Для учета только новых операций — текущий остаток.

Комиссия за конвертацию задается в процентах отдельно для каждого счета. Оставьте 0, если комиссия неизвестна или ее нет. Процент добавляется к сумме валютного расхода по курсу Visa до округления. Это оценка учета; сверяйте ее с фактическим списанием банка. Предыдущие записи не пересчитываются при изменении процента.

## 3. Добавьте первую операцию

Кнопка **+** или ⌘N открывает создание операции. Укажите тип, описание, дату, сумму, счет и категорию. При валюте покупки, отличной от валюты счета, Mora запросит курс Visa; без курса запись не сохраняется.

Перевод между собственными счетами не считается доходом или расходом. Для разных валют укажите фактическую сумму зачисления.

## 4. Импортируйте историю при необходимости

**Импорт → Из CSV-файла** открывает сопоставление колонок и предпросмотр. Примеры вымышленных данных лежат в [Examples](../Examples). Проверьте знак суммы, валюту, счет и даты. Снимите отметки с ненужных строк и только затем подтвердите импорт.

**Выписка или скриншот через AI.** Откройте **Импорт → Через AI-агента**, выберите подготовку CSV или запись через MCP и нажмите **Открыть ChatGPT**. Черновик откроется в приложении ChatGPT. В конце инструкции дополните **Мой запрос**, например: «Добавь только первую и третью операции на счет …», и приложите скриншот или выписку в чате. Файлы и описание задаются в чате. Агент уточнит недостающее одним вопросом и продолжит после ответа.

MCP устанавливать не обязательно: при локальном выполнении агент использует компонент из Mora.app. Без доступа к Mac он подготовит CSV-файл для открытия и предпросмотра в Mora. При первом запуске уточнит имя, валюту и начальный остаток счета; демонстрационные счета в промпт не включаются.

История импортов позволяет отменить весь пакет. Если операции из него редактировались, приложение предупредит перед отменой.

## 5. Посмотрите итоги и сохраните копию

Overview показывает выбранный месяц. **All transactions →** открывает операции, **All analytics →** — подробную аналитику с тем же месяцем.

Через **Финансы → Сохранить резервную копию** сохраните JSON в защищенном месте. Не отправляйте его в GitHub. Для скриншотов включите скрытие сумм и проверьте, что названия, заметки и другие личные сведения тоже не видны.

Облако и AI не нужны для начала. Подключайте их только после знакомства с [обработкой данных](PRIVACY.md).
