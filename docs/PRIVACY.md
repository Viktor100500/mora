# Конфиденциальность Mora

## Локальный учет

Счета, операции, категории и история находятся в `~/Library/Application Support/Mora/`. Основной файл — `ledger.json`; предыдущая исправная копия — `ledger.json.backup`. Файлы создаются с ограниченными правами, но приложение не шифрует их само. Полная JSON-копия содержит финансовую историю, заметки и историю изменений.

Приложение не содержит рекламной аналитики или телеметрии разработчика. Публичная сборка не содержит пользовательской базы, адреса заранее настроенного облака или личных ключей.

## Сетевые запросы

| Функция | Получатель | Что отправляется |
| --- | --- | --- |
| Автоматические курсы | ExchangeRate-API | Запрос общей таблицы относительно USD; счета и операции не отправляются |
| Валютный расход | Публичный калькулятор Visa | Валютная пара, дата и единичная сумма для определения курса; имена счетов, номер карты и сумма покупки не передаются |
| Общая база, если подключена | Ваш Supabase-проект | Снимок учета, операции и информация синхронизации; сквозного шифрования нет |
| Категории новых продавцов, если включены | GitHub Raw и jsDelivr | Загрузка общих каталогов Merchant Studio и NSI; названия покупок, суммы и операции не отправляются |
| AI, если вы им пользуетесь | Выбранный AI-провайдер | Содержимое подготовленного промпта и результаты вызванных вами инструментов MCP |
| Wallet, если настроен | Ваш Supabase-проект | Доступные сведения покупки и ключ отправки из вашей команды iPhone |

Автоматические справочные курсы можно выключить в настройках. Для первого пересчета Visa за день нужна сеть. Курс сохраняется локально до следующего дня UTC отдельно для даты покупки и направления валютной пары; этот кеш не содержит сведений о покупках или счетах. Облако и MCP настраиваются отдельно, регистрации для локального режима нет.

## Сессии и резервные копии

Облачная сессия хранится в Связке ключей macOS. Сетевые параметры, локальные контрольные снимки, коды подключения и телефонные ключи не предназначены для публикации. Администратор вашего облачного проекта может читать его данные.

Скриншот с замаскированными суммами все еще может содержать названия счетов, продавцов или заметки. Перед публикацией используйте демо либо вымышленные данные и проверяйте весь снимок.

## GitHub

Публичный репозиторий содержит только код, инструкции и явно синтетические тесты. Личные данные не нужны для сообщений об ошибках. Если обнаружили утечку, следуйте [SECURITY.md](../SECURITY.md); не публикуйте сам секрет в Issue.

Категории новых продавцов можно выключить в настройках. В этом случае остаются ваши правила и история продавцов. Сопоставление открытых каталогов выполняется внутри Mora. В приложение также включен снимок Overture Places для Нью-Йорка и окрестностей и открытого реестра продуктовых магазинов штата Нью-Йорк; он работает без сети. Общие каталоги брендов сохраняются в локальном кеше и остаются доступными при ошибке обновления. Названия покупок не используются в сетевых запросах к справочникам. Покрытие и обновление снимка описаны в [документации категорий](merchant-categories.md).
