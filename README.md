# Mora

**Личные финансы для macOS: счета в разных валютах, расходы, CSV и аналитика.**

Native macOS personal finance app. Local storage by default, Russian and English UI. Source available under a restricted license; see [LICENSE](LICENSE).

[Скачать приложение](https://github.com/Viktor100500/mora/releases) · [Первый запуск](docs/GETTING-STARTED.md) · [Конфиденциальность](docs/PRIVACY.md) · [История версий](CHANGELOG.md)

## Установка

Нужна **macOS 14 или новее**. В [Releases](https://github.com/Viktor100500/mora/releases) выберите архив своей архитектуры:

- `arm64` — Mac с Apple Silicon: M1, M2 и более новые.
- `x86_64` — Mac с процессором Intel, если такая сборка приложена к релизу.

Распакуйте ZIP, перенесите `Mora.app` в **Программы** и откройте. Python, регистрация и собственный сервер для обычного учета не нужны.

**Первые релизы — preview.** Они подписаны локальной подписью, а не сертификатом Developer ID, и пока не нотарифицированы Apple. macOS может заблокировать первый запуск. После проверки источника используйте штатный пункт **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**, если он доступен. Не отключайте Gatekeeper целиком. Подробнее: [инструкция Apple](https://support.apple.com/guide/mac-help/open-an-app-by-overriding-security-settings-mh40617/mac).

SHA-256 каждого архива приложен рядом с ним. После загрузки можно сравнить его командой `shasum -a 256 имя-архива.zip`.

## Первые пять минут

1. На экране приветствия выберите русский или английский язык и валюту отчетов.
2. Нажмите **Создать первый счет**. Для знакомства можно сначала посмотреть демо: данные в нем вымышленные, изменения не сохраняются.
3. Укажите имя счета, его валюту и начальный остаток. При импорте истории это остаток **перед самой ранней операцией**, а не текущий баланс.
4. Добавьте расход или импортируйте CSV. Проверьте предпросмотр перед записью.
5. Откройте Overview и Analytics, затем сохраните первую резервную копию через меню **Финансы**.

Счета могут иметь разные валюты. Валюта отчетов объединяет итоги и не меняет валюты счетов. Подробнее — [пошаговое руководство](docs/GETTING-STARTED.md).

## Возможности

- **Обзор:** общий капитал, доходы и расходы месяца, движение денег и категории. Кнопки All transactions и All analytics ведут к подробностям.
- **Операции:** поиск, фильтры, редактирование, теги, заметки, разделение по категориям и переводы между своими счетами.
- **Счета:** банковские, наличные, накопления, инвестиции и кредитные; начальные остатки и архивирование.
- **Валюты:** автоматические справочные курсы, пересчет валютных расходов по Visa и отдельная процентная комиссия для каждого счета. Сохраненная комиссия не меняется при изменении настройки счета.
- **CSV:** сопоставление колонок, предпросмотр, выбор строк, обнаружение повторов, экспорт и история импортов с отменой пакета.
- **Аналитика:** категории, динамика за 12 месяцев и календарь расходов.
- **Планы:** бюджеты, цели и регулярные платежи; включаются в настройках.
- **Управление данными:** резервные копии JSON, отмена и возврат последних изменений, скрытие сумм для скриншотов.
- **Интерфейс:** русский и английский языки, светлая и темная темы.

Mora не подключается к банковским счетам автоматически и не переводит деньги. Переводы внутри приложения — записи учета. Инвестиционные счета учитывают ручной денежный остаток; котировки и расчет доходности не загружаются.

Справочные курсы применяются к отчетам всей истории; они не заменяют подтвержденные курсы банковских выписок. Для перевода между разными валютами вводите фактическую сумму зачисления. Комиссия за конвертацию применяется к валютным расходам, а не к произвольным банковским переводам.

## Дополнительные интеграции

**AI-импорт.** Выберите **Импорт → Через AI-агента**, способ импорта и **Открыть ChatGPT**. Приложение ChatGPT откроет черновик с инструкцией и контекстом счетов. В конце промпта есть раздел **Мой запрос**: дополните его и приложите скриншот или выписку прямо в чате. Агент соберет необходимые уточнения в один вопрос. Для прямой записи он использует доступный MCP или встроенный MoraBridge без установки MCP и Python; если локальный доступ недоступен — подготовит CSV-файл для Mora. На первом запуске помощник уточнит данные для создания счета.

[Локальный MCP](mcp/README.md) остается дополнительной интеграцией для совместимых помощников; только для него нужен отдельный Python 3.10+. При работе с AI переданные документы, контекст счетов, локальные пути запуска и результаты инструментов доступны выбранному вами провайдеру.

**Общая база и Apple Pay.** [Необязательный модуль](cloud/README.md) работает с вашим собственным проектом Supabase. В сборку не включены чужие учетные записи, проекты или ключи. Wallet через «Быстрые команды» — экспериментальная интеграция: покупки могут требовать ручной проверки, офлайн-очереди нет.

## Ваши данные

По умолчанию учет локальный: `~/Library/Application Support/Mora/ledger.json`. Полная резервная копия JSON включает финансовую историю; CSV содержит только операции. Mora не шифрует локальные файлы самостоятельно.

GitHub содержит код, документацию и синтетические примеры. Пользовательские базы, выписки, резервные копии, облачные настройки, токены, личные команды iPhone и конфигурация конкретного компьютера в него не включаются. В проекте есть список исключений и проверка файлов перед публикацией. Это не повод добавлять настоящие данные в Issues или скриншоты.

Подробности о сетевых запросах и хранении — в [PRIVACY.md](docs/PRIVACY.md).

## Сборка из исходников

Нужны macOS 14+, Swift 6 и Command Line Tools или Xcode:

```sh
git clone https://github.com/Viktor100500/mora.git
cd mora
zsh scripts/build-app.sh
open build/Mora.app
```

Приложение — SwiftUI и Swift Charts, без сторонних библиотек в исполняемом файле. Денежные значения обрабатываются через `Decimal`. Сборка соответствует архитектуре текущего Mac.

Проверки:

```sh
swift test
python3 scripts/check-publication.py --tree HEAD
```
