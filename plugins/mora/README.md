# Mora — локальный плагин

Плагин для ChatGPT Work и Codex на Mac. Компонент Mora запускается самим клиентом через локальный MCP; отдельный сервер в интернете, туннель и API-ключ не нужны. Плагин читает ту же базу, что и приложение Mora, и записывает изменения через штатные проверки и блокировки.

## Использование

В ChatGPT на Mac откройте новый чат Work с локальным выполнением и включите Mora. Например:

- «Покажи мои счета и категории в Mora».
- «Запиши кофе 320 RSD с моего счета в динарах».
- «Покажи расходы по категориям за этот месяц».

Помощник получает актуальные счета и категории, уточняет неоднозначности и проверяет операции до записи. Если вы не указали или не подтвердили счет для этих операций, помощник спросит его, даже когда есть только один счет в нужной валюте. База остается на Mac; результаты вызванных инструментов передаются используемой модели в чате. Mora можно закрыть: плагин работает с базой самостоятельно. Приложение должно быть обновлено до 1.3, если остается открытым во время записи через плагин.

## Что доступно

Счета и остатки, категории, список операций, месячные отчеты; запись расходов, доходов и переводов; импорт стандартного CSV; создание учетного счета, бюджета, цели и расписания расхода. Банковские платежи не выполняются. Исправление счета старых расходов и доходов доступно через MCP; остальные изменения и удаления выполняются в Mora. Суммы можно передавать в исходной валюте: Mora автоматически пересчитывает их по курсу Visa в валюту выбранного счета и сохраняет исходные данные. Пакеты из чата видны в истории импортов.

Этот локальный вариант требует доступа к Mac. Обычный облачный веб-чат и телефон не могут самостоятельно запустить его локальный процесс.

## Сборка и перенос

В проекте Mora выполните `python3 scripts/build-chatgpt-plugin.py`. Пакет создается в `build/ChatGPTPlugin/mora`, архив — `build/ChatGPTPlugin/Mora-ChatGPT.zip`. Архив содержит только код, инструкции, значок и MoraBridge; счета, операции и ключи в него не включаются.

Среда Python MCP установлена отдельно в `.venv` проекта. На другом Mac сначала выполните `scripts/setup-mcp.sh` в перенесенном проекте, затем пересоберите плагин для новых путей и архитектуры. Также можно указать `MORA_PYTHON` с путем к Python, где установлены зависимости `MCP/requirements.txt`.

Установка из локального источника: зарегистрируйте каталог `build/ChatGPTPlugin` как marketplace и установите `mora@mora-local`. Перезапуск всего приложения не обязателен для проверки из нового чата, если клиент подхватывает обновленные плагины; текущий чат сохраняет прежний набор инструментов до перезагрузки.
